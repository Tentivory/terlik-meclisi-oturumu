# TERLİK MECLİSİ OTURUMU

Resmi ad: Koridor Yasama Organı. Gayriresmi ad: Ayakkabılığın vicdanı.

Bu depo, bir evin girişinde unutulmuş nesnelerin anayasal düzenini simüle eder. Kod çalışır. Meclis çalışmaz. Bu, gerçek hayattaki bazı meclislerle tek ortak noktadır ve bunu burada yüksek sesle söylemiyoruz.

## Nedir bu

`python oturum.py` yazarsın. Terlikler gündeme madde alır. Askılık usul tartışması açar. Kapı zili her oylamada "birisi geldi" diye divanı keser. Sonunda bir karar çıkar. Karar genellikle "terlikler sağa çevrilsin, sol ideolojiktir" değildir. Karar genellikle "paspas konuşmasın" olur.

## Neden ciddiye almalısın

Almamalısın. Ama aldıysan sorun bizde değil, koridorda.

## Kurulum

```bash
git clone https://github.com/Tentivory/terlik-meclisi-oturumu
cd terlik-meclisi-oturumu
python oturum.py
```

Bağımlılık yok. Python 3 yeter. İnternet gerekmez. Demokrasi de gerekmez, ama varmış gibi yapıyoruz, çünkü tutanak böyle istiyor.
